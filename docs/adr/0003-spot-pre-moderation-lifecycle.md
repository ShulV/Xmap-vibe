# Pre-moderation for Spot Submissions

We decided that spot creation by authenticated riders creates a proposal in `PENDING_REVIEW` status rather than immediately publishing to the public map. The spot is only visible on the public map once reviewed and set to `APPROVED` by a moderator (`ROLE_MODERATOR` / `ROLE_ADMIN`). This ensures quality control, prevents duplicate or spam spots, and protects the integrity of the community map.
